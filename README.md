# 🚀 Galaxy Explorer - Responsive Landing Page

## Project Overview

Galaxy Explorer is a modern and responsive landing page built using HTML5 and CSS3. The website is inspired by space tourism and showcases a futuristic design with multiple sections, including a hero section, about section, features, statistics, testimonials, FAQ, and footer.

The project demonstrates the use of responsive web design techniques to ensure a seamless experience across desktop, tablet, and mobile devices.

---

## Features

* Responsive navigation bar
* Full-screen hero section
* About Us section
* Feature cards with hover effects
* Statistics section
* Customer testimonials
* Frequently Asked Questions (FAQ)
* Call-to-action section
* Footer with social links
* Smooth scrolling navigation
* Mobile-friendly layout using media queries

---

## Technologies Used

* HTML5
* CSS3
* Flexbox
* Media Queries

## How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension (if not already installed).
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. View the website in your browser.
